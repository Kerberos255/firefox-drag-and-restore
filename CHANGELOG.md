# Changelog

## 1.0 — 2026-09-10

Initial public release.

- Super drag for links and images.
- Optional drag-to-search for selected text using Firefox's configured search engine.
- Restore the most recently closed tab from the toolbar button.
- Right-click the toolbar button to restore a recent tab or restore all recent closed tabs.
- Settings for drag behavior, image dragging, background tabs, text search, and minimum drag distance.
- Light and dark toolbar icons.
- Simplified Chinese and English localization.
