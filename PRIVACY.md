# Privacy Policy

Last updated: 2026-09-10

Drag & Restore is designed to work locally in Firefox and does not include analytics, telemetry, advertising, tracking, a remote backend, or remote code.

## Data handled by the extension

### Link and image dragging

When you drag a link or image to open it in a new tab, the extension uses the dragged URL only to create that tab in Firefox. The extension does not send that URL to the developer or to any separate service.

### Restore closed tabs

The extension uses Firefox's `sessions` API to read and restore recently closed tabs. This information stays inside Firefox and is not transmitted to the developer or to any separate service.

### Text search

Text-search dragging is disabled by default. If you enable it, Firefox asks for the optional `searchTerms` data-transmission permission.

When this feature is enabled and you drag selected text to search, the selected text is passed through Firefox's search API to your configured search engine so that the search can be performed. The developer does not receive, store, or otherwise process those search terms.

You can disable text-search dragging at any time from the extension's settings.

## Local settings

The extension stores its preferences using Firefox's local extension storage. These settings are not transmitted to the developer or to any separate service.

## Third parties

Drag & Restore does not operate its own server. If you choose to use text-search dragging, your configured search engine receives the search query as part of performing that search and its own privacy policy applies.

## Changes

If the extension's data practices change, this policy will be updated before a version using those new practices is released.

## Contact

For questions or issues, use the support channel linked from the extension's AMO listing or project repository.
